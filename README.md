
A mod for Rimworld that adds a separate bar on screen for mechanoids.

Current supported versions: **1.6**

**Steam Workshop**: 

There is a toggle to hide and unhide it. You can adjust panel position, icon size, spacing and health bar visibility. 

Highlight colors: none - default, blue - selected, green - drafted.

Built to be similar to Colonist Bar Adjuster. Adapted some code logic from there:
https://steamcommunity.com/sharedfiles/filedetails/?id=2673413930 (https://github.com/XT-0xFF/ColonistBarAdjuster)
